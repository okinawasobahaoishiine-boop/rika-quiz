# テスト版の作業ルール

- 正式な編集先はこのpreviewフォルダ。本番は親フォルダの5ファイル。両方を手で別々に編集しない。
- 「更新して」「直して」は、このテスト版だけの更新として扱う。本番へのコピー・公開は「本番に反映して」という明示依頼が必要。
- 上位のAGENTS.mdに従う。ただし更新先を本番ルートと誤認しない。
- 公開URL：https://okinawasobahaoishiine-boop.github.io/rika-quiz/preview/
- 同じオリジンなのでlocalStorage自体は共有。必ずrikaQuizPreview:のキー接頭辞を使う。既存の本番キーを読み書き・削除しない。
- SCIENCE_IS_PREVIEWで保存キー、バナー、クラウド無効化を制御。本番パスでは従来キーとクラウドが有効になる。同じコードを昇格し、環境差分を手作業で書き換えない。
- テスト版で本番Supabaseクライアントを作成しない。匿名ログイン・プロフィール・学習記録を送信しない。
- テスト版の名前・学年は初回に別途設定。本番からコピーしない。テスト版バックアップも本番に復元しない。
- スクリプトとCSSのURL版番号を更新してスマホの旧キャッシュ混入を防ぐ。
- 本番反映は ../scripts/promote-preview.cjs を確認し、ユーザー承認後にのみ --apply を使う。コピーした差分を検査・テストしてからコミットし、通常の公開承認に従う。
